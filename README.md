# TechFix - Landing Page 💻

## 📌 Sobre a empresa
A TechFix é uma startup de tecnologia que trabalha com soluções e serviços tecnológicos.
A empresa atua com desenvolvimento de sistemas e soluções digitais, suporte e manutenção de computadores, design gráfico, UX/UI, testes de software e outras soluções relacionadas à tecnologia.

## 👨‍💻 Características do desenvolvimento
* Protótipo feito no figma
* Responsivo para dispositivos móveis
* Seções organizadas em componentes reutilizáveis
* Chamadas com foco em conversão

## 🔧 Ferramentas Usadas
* Next.js - Framework React usado
* Typescript - Para garantir maio robustez
* React-toastify - Exibição de mensagens de feedback
* Axios - Facilitar as requisições HTTP
